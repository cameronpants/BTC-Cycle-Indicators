Structural — long-cycle valuation

the classic checklist

Pi Cycle Top and Mayer Multiple are pure price-moving-average metrics, so they're computed live from free price history. MVRV Z-Score, NUPL, and RHODL Ratio need realized-cap on-chain data that has no free API (Glassnode's API has no free tier) — those stay manual, pulled from the free chart pages noted.

Pulse — leverage & sentiment

catches sharper, shorter tops

Funding, open interest, long/short skew, and Fear & Greed all come from free, no-key public endpoints (Binance futures API + Alternative.me).

Institutional era

didn't exist last cycle

Stablecoin Supply Ratio is computable from free CoinGecko market-cap data. ETF flows, exchange netflow, and treasury pace have no official free API — nobody publishes one — so they stay manual.

Macro backdrop

the tide underneath

DXY and real yields live at FRED, which requires a free API key and doesn't allow direct browser calls (no CORS) — so these stay manual pulls from TradingView/FRED.

What's live vs. manual, and why: "auto" rows pull from CoinGecko, Binance's public futures API, and Alternative.me — all free, keyless, CORS-enabled endpoints. "Manual" rows are metrics that simply have no free public API today (Glassnode/CryptoQuant charge for API access even though their charts are free to view; ETF-flow and treasury-tracking sites don't publish an API at all). Values you type in are saved to this browser's local storage only — nothing leaves your machine except the API calls themselves.

Not financial advice — a tracking aid, not a signal generator.
